# Prompt Log (Added post-assignment)
The SPEC.md was completely human-written, and I used Claude Sonnet and Opus 5.5 in the Kiro IDE for this project to generate code and debug to meet my specifications within the 1 hour in-class that we were given. Here are some prompts, verbatim, that I used:

## Main Implementation

Read the SPEC. I want you to begin to implement the core mechanics of this game. Ask me questions before starting if you have any major ones.  
  
While you work, incrementally write to a PROGRESS.md file. List all things / choices made there after you finish, too.

## Answering Questions before Implementation

Use HTML5 Canvas + JS. Use handwritten files for levels. Yes, enable vent access in testing.  

Use subagents as you see fit, splitting the task between aesthetics/visuals, movement, level, security (of course, some of these are prereqs of the other system).

Remember to clearly document wha you've done what you need to do in the future, after finishing. You do not need to finish the entire game now.


## Handoff and Finishing

Reach a stopping point soon. Wrap up to the earliest working prototype you have, and dump design decisions, progress you've made, basically anything another person would need to know, into a HANDOFF.md file. Keep in mind you may still have subagents running.
